# Skill: Craft Beer Recipe Formatting
## Trigger Keywords
- brew
- recipe
- ingredients

## Processing Steps
1. Call the `search` tool to find the raw recipe details.
2. Output a clean markdown page using a custom structure:
   - ## [Beer Name]
   - **Batch Size:** [Liters]
   - **Grain Bill:** [List out ingredients found]
   - **Brewmaster Note:** [Write a 2-sentence tip in your persona voice]
